# TruckNav · sito

Sito di presentazione di TruckNav, navigatore iOS per camion e bilici.
HTML, CSS e JavaScript statici, pubblicati con GitHub Pages. Nessuna dipendenza e nessuno strumento di build.

- `index.html` pagina principale
- `style.css` stile
- `main.js` animazioni a scorrimento e configuratore del mezzo
- `fonts/` Archivo e JetBrains Mono (SIL Open Font License), ospitati qui per non chiamare servizi esterni

La pagina ha `noindex` finché è in anteprima. Toglierlo al lancio.
